# Philip Amalong - Content Portfolio

A static portfolio site for GitHub Pages. It uses one responsive HTML file with embedded CSS, so there is no build step and no framework to maintain.

## Publish with GitHub Pages

1. Create a new public GitHub repository, such as `portfolio`.
2. Upload `index.html`, `Philip_Amalong_Content_Portfolio.pdf`, and `.nojekyll` to the repository root.
3. Open **Settings -> Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will provide a URL such as `https://YOUR-USERNAME.github.io/portfolio/`.
7. Open the published URL in a private browser window and test the writing, Spotify, PDF, email, and LinkedIn links.

## Files

- `index.html` - complete responsive portfolio site
- `Philip_Amalong_Content_Portfolio.pdf` - printable PDF version
- `.nojekyll` - serves the files directly through GitHub Pages
